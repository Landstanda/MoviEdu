# ComfyUI flashcard loop

MoviEdu generates spelling pictures **locally with ComfyUI**, one PNG per word (`cat.png`, `bag.png`, …). Nothing is scraped from the web. There is no LangGraph or Unsloth Studio in this loop — a Python `for` loop walks a spreadsheet and POSTs one Comfy graph per row.

## Layout

| Path | Role |
|------|------|
| `education/kindergarten/words.csv` | Word list. Filter with `moviedu_priority` (this round: `start-here`) |
| `tools/comfy/spelling_prompts.py` | `SUBJECTS[word]` + shared photoreal trailer. Homographs are fixed here (`bat` = baseball bat, `jam` = jar, `fan` = desk fan, `red` = apple, `cap` = baseball cap) |
| `tools/comfy/generate_spelling_images.py` | Reads the CSV, queues Comfy, copies to `assets/spelling/<word>.png`, rewrites `src/spellingImages.ts` |
| `assets/spelling/` | Bundled flashcards the app loads |
| `src/spellingImages.ts` | Metro `require()` map. Regenerated by the script; do not edit by hand |

The app looks up `word + ".png"` (bundled). A parent-picked photo still wins if `image_uri` is set.

## Prerequisites

1. ComfyUI running on this machine: [http://127.0.0.1:8188](http://127.0.0.1:8188)
2. Workflow / weights (Boogu Turbo T2I):
   - UNET `boogu_image_turbo_fp8_scaled.safetensors`
   - CLIP `qwen3vl_8b_fp8_scaled.safetensors` type `boogu`
   - VAE `ae.safetensors`
   - Sampler: 4 steps, CFG 1, `lcm`, `sgm_uniform`
   - Size: **640×480** (4:3 flashcards)
3. Comfy writes under `E:\ComfyUI\ComfyUI\output\spelling_k\`, then the script copies and renames. Override with `--comfy-output` or env `COMFY_OUTPUT` if that folder moves.

Python stdlib only (`csv`, `urllib`). No pandas, no LangGraph.

## Run a full set (row by row)

From the **MoviEdu repo root**:

```bat
python tools/comfy/generate_spelling_images.py
```

That:

1. Reads `education/kindergarten/words.csv`
2. Keeps rows where `moviedu_priority` is `start-here` (~79 words)
3. For each word, skips if `assets/spelling/<word>.png` already exists
4. Otherwise POSTs one prompt (`prompt_for(word)`), waits, copies the PNG
5. Writes `src/spellingImages.ts` so Metro can `require` every file

Do **not** regenerate pictures that already look good. Delete that one PNG (or pass `--force` for a named subset) if you want a new take.

## Other loops

| Goal | Command |
|------|---------|
| Next priority band | `python tools/comfy/generate_spelling_images.py --priority good-fit` |
| Several bands | `--priority start-here --priority good-fit` |
| Every CSV row that has a prompt | `--all-rows` |
| One or a few words | `--words cat,bag` |
| Redo one word | delete `assets/spelling/cat.png` then `--words cat`, or `--words cat --force` |
| First N only (smoke) | `--limit 3` |
| Comfy on another port | `--comfy http://127.0.0.1:8188` |
| Refresh the JS map only | `--map-only` |

Before a new band, add that word to `SUBJECTS` in `spelling_prompts.py`. The script exits if a selected CSV row has no prompt.

## After new PNGs

Rebuild or reload the Android app so Metro picks up new `require()` entries. On first launch the app **seeds** any bundled word that is not already in SQLite (existing custom words are left alone). Lessons resolve `bag.png` / `cat.png` from `SPELLING_IMAGES` even when `image_uri` is empty.

## Adding a new word later

1. Put the row in `words.csv` (or pass `--words`).
2. Add `SUBJECTS["word"]` in `spelling_prompts.py`.
3. Run the generator (Comfy up).
4. Confirm `assets/spelling/<word>.png` and a matching line in `src/spellingImages.ts`.
