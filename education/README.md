# Education plans

Curriculum notes and word lists for MoviEdu, aligned to **California** kindergarten (and later grades) expectations.

| Folder | What is in it |
|--------|----------------|
| [kindergarten/](kindergarten/) | Words a California kindergartener should read and spell, by time of year |
| [../tools/comfy/](../tools/comfy/) | Local ComfyUI loop: CSV row → `assets/spelling/<word>.png` |

Open `kindergarten/words.csv` in Excel, Google Sheets, or Numbers. Filter on `spell_band` and `moviedu_priority` to build a generation batch. To render a whole band of flashcards, start ComfyUI and run the commands in [tools/comfy/README.md](../tools/comfy/README.md).
